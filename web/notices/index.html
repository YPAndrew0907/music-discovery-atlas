Credits and dependency notices

This web package includes the public FMA metadata, derived vectors, six recorded demonstration queries, browser source and pinned ONNX Runtime Web 1.23.2 runtime. Model weights and audio are not included. The optional browser engine downloads the exact pinned Xenova CLAP text model and tokenizer from Hugging Face only when enabled.

The runtime MIT license and upstream third-party notices are supplied unchanged. The upstream notices are a superset and do not imply that every listed component is present in the WebAssembly artifact. Model cards and model/tokenizer licenses are included for the optional download. Conditional source-ancestry notices preserve upstream attribution without asserting that each source component is bundled.
