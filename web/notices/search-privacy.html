Search privacy

A ready server processes descriptions only when you submit them with Find music. Your exact submitted description is sent to this site's same-origin server for model inference and search over this collection. Typing, opening the page, checking readiness and changing search engines do not send your description.

Application query and access logging is disabled in this service's hosting configuration, and application error messages are redacted. The hosting provider may retain infrastructure and connection metadata. This is not a promise of zero retention across the hosting infrastructure.

Recorded-example buttons replay saved public queries in this browser. Title / artist lookup and audio-neighbor exploration also stay in this page. Choosing the optional on-device model keeps descriptions in this browser; its model and tokenizer downloads go to Hugging Face, which receives the download request and connection metadata. Downloads begin only after you choose Download & enable.

Server availability checks send no query text. Search cancellation sends only the request ID and generation. Kept tracks stay in the page session unless you export them.
