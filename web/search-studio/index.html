    How search and the map work
    IndexExaminedFrontierMatches

    This sample indexes 108 public FMA recording records and audio-derived vectors. It is small and biased and does not represent mainstream music. Audio is not bundled. A recording can play only when this deployment publishes a verified same-origin preview for it.

    A paired CLAP model compares descriptions and audio in 512 dimensions. The map is a fixed approximate view; positions do not determine results, and islands are not learned genres.

    The animation condenses actual HNSW candidate visits into a few trace-backed moments on this same catalog. Context lines are genuine stored index connections; the frontier shows the available candidate-queue snapshot, which is capped at 16 entries. The final focus reveals the exact displayed matches, not a trained confidence field. Exact scoring supplies results immediately. At this size an exact scan is already fast; the graph is an explanation of the index, not a claim of acceleration.

    More artists is an optional display policy: it prefers one recording per source artist within the closest 16 sound candidates, then fills remaining places from that same pool. The first sound match and every original similarity score are preserved. This trades some sound similarity for artist breadth; it is not a measured relevance improvement.

    Language, instruments, vocals and mood are not independently verified constraints. A phrase such as “no vocals” is a preference, not a guaranteed filter.
